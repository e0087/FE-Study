# FE Study

基本情報技術者試験向けの端末内学習アプリです。回答履歴はブラウザー内に保存します。

## 問題データ

標準問題は `data/` 以下のJSONバンクとして管理します。`src/questions.js` の `banks` に相対パスを追加すると問題セットを増やせます。JSONは `schemaVersion: 1` と `questions` 配列を持ち、問題文・選択肢の各要素は `text`、`code`、`image`、`table` ブロックに対応します。画像はアプリ配下のファイルを相対パスで指定してください。表は `headers` と `rows` を持ちます。

演習では選択肢の並びを表示ごとにシャッフルします。回答後は正解・不正解を問わず、各選択肢の解説を確認できます。

令和8年度 科目A・科目B公開問題はそれぞれ `data/public/2026-r08-fe-a.json`、`data/public/2026-r08-fe-b.json` に収録しています。問題文と選択肢は公開資料の内容に沿って掲載しています。出典は各問題の `source.label` に記載し、IPA解答例とFE Study作成の解説を別項目で明示しています。コード・表・図はアプリで読みやすいブロック表示にしています。科目Aの図版は `data/public/2026-r08-fe-a/` に置いています。IPAの利用条件に従って出典を保持し、問題制度の意義に反しない教育目的で利用してください。

新しい問題データや画像を追加した場合は、Service Workerの `APP_FILES` にも登録してください。キャッシュバージョンを更新すると、利用端末で新しいデータに切り替わります。
